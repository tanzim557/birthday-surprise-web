# Cyber-Magical Birthday Surprise Web Experience

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://html.spec.whatwg.org/)

An interactive, gamified single-page birthday surprise web experience. Engineered with modern HTML5, Tailwind CSS, GSAP timelines, Canvas Confetti, and the Web Audio API.

---

## Key Features

- Interactive Gamified Gift Box: Multi-stage gift box unlocking sequence with smooth animations and sound effects.
- Web Audio Melodic Engine: Synthesizes and plays celebratory sound effects and birthday melodies directly in the browser.
- Dynamic Confetti Cannons: Multi-directional particle bursts synchronized with surprise milestones.
- Memory Carousel and Wishes: Personalized memory card gallery with smooth GSAP transitions.

---

## Getting Started

Simply clone and open index.html in any web browser, or serve with a local server:
```bash
git clone https://github.com/tanzim557/birthday-surprise-web.git
cd birthday-surprise-web

# Using any static server
npx serve .
```
